1. Calibration에 사용된 알고리즘¶

Levenberg-Marquardt (LM) 알고리즘¶

  1. 비선형 최적화 문제에 많이 사용
  2. Jacobian을 활용하여, 빠른 수렴과 안정성이 높음.

from scipy.optimize import least_squares
import numpy as np
import scipy.io
import matplotlib.pyplot as plt
from scipy.optimize import minimize


# 데이터 로드
data = scipy.io.loadmat('robot_data.mat')
theta1_train = data['theta1_train'].flatten()
theta2_train = data['theta2_train'].flatten()
p_train = data['pTrain'][:2, :]  # (2 x N)


# Forward Kinematics
def forward_kinematics(theta1, theta2, a1, a2):
    x = a1 * np.cos(theta1) + a2 * np.cos(theta1 + theta2)
    y = a1 * np.sin(theta1) + a2 * np.sin(theta1 + theta2)
    return np.vstack((x, y))  # 2 x N

#다른 최적화 알고리즘을 위해 정의
def jacobian(params):
    a1, a2 = params
    c1 = np.cos(theta1_train)
    s1 = np.sin(theta1_train)
    c12 = np.cos(theta1_train + theta2_train)
    s12 = np.sin(theta1_train + theta2_train)

    # 각 샘플에 대해 ∂x/∂a1, ∂x/∂a2, ∂y/∂a1, ∂y/∂a2 계산
    J = np.zeros((2 * len(theta1_train), 2))  # (2N x 2)

    # ∂x/∂a1, ∂x/∂a2
    J[0::2, 0] = c1
    J[0::2, 1] = c12

    # ∂y/∂a1, ∂y/∂a2
    J[1::2, 0] = s1
    J[1::2, 1] = s12

    return J

# residuals 함수: 예측 - 실제
def residuals(params):
    a1, a2 = params
    pred = forward_kinematics(theta1_train, theta2_train, a1, a2)
    diff = pred - p_train  # shape: (2, N)

    # reshape to (2N, ) with interleaved format: [x1, y1, x2, y2, ...]
    return diff.flatten()  # transpose 먼저, 그 다음 flatten

def loss(params):
    a1, a2 = params
    p_pred = forward_kinematics(theta1_train, theta2_train, a1, a2)
    error = p_pred - p_train
    return np.sum(error**2)

# 초기값
x0 = [0.1, 0.2]

# 최적화 실행 (LM 방식)
#res = least_squares(residuals, x0, bounds=([0.05, 0.15], [0.15, 0.35]), method='trf')
res = least_squares(residuals, x0, method='lm')

오차값에 대한 고찰¶

※ 오차값이 큰 이유를 확인하기 위해, train data의 최대/최소값을 확인해보면 다음과 같음.

X 축: 최소값 = -0.0409, 최대값 = 0.3818
Y 축: 최소값 = 0.1056, 최대값 = 0.3765

문제에서 주어진 link의 길이가 $a_1 = 0.1 $ , $a_2 = 0.2$ 이나, 두 링크의 길이 합보다 최대/최소값의 크기가 더 크게 나오는 것으로 볼때, simulink의 데이터 생성 과정에서 노이즈 크기를 줄여볼 필요가 있을것 같음.

※ 다른 최적화 알고리즘을 검토해보았으나 (Quasi-Newton) 유의미한 개선은 없음.
